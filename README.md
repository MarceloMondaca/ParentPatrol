# ParentPatrol 🛡️

> **Protege. Guía. Acompaña.**

ParentPatrol es una aplicación Android de control y acompañamiento parental, diseñada para ayudar a padres y tutores a gestionar de forma responsable la experiencia digital de sus hijos.

## 🚧 Estado del proyecto

ParentPatrol se encuentra actualmente en desarrollo.

## 🎯 Objetivo

El proyecto busca proporcionar herramientas que permitan a padres y tutores establecer límites saludables en el uso de dispositivos Android y acompañar la actividad digital de sus hijos.

Entre las funcionalidades previstas se encuentran:

- Gestión del tiempo de uso.
- Perfiles infantiles según edad.
- Autorización mediante PIN o biometría.
- Información sobre tiempo de pantalla y uso de aplicaciones.
- Herramientas de protección y acompañamiento digital.

## 🛠️ Tecnologías

- Kotlin
- Jetpack Compose
- Material 3
- Arquitectura MVVM
- Android SDK

## 📱 Compatibilidad

Android 8.0 (API 26) o superior.
